var (inferred), explicit types, const, readonly

If / Switch control flow
If Statements & Switch Expressions Interview Fav
Modern switch expressions (C# 8+) are much cleaner than switch statements
int score = 85;

if (score >= 90) Console.WriteLine("A");
else if (score >= 80) Console.WriteLine("B");
else Console.WriteLine("C");

// ternary
string result = score >= 60 ? "Pass" : "Fail";

// classic switch statement
switch (score / 10)
{
    case 10:
    case 9: Console.WriteLine("A"); break;
    case 8: Console.WriteLine("B"); break;
    default: Console.WriteLine("C or below"); break;
}

// switch EXPRESSION (C# 8+) — no break statements, returns a value
string grade = score switch
{
    >= 90 => "A",
    >= 80 => "B",
    >= 70 => "C",
    _ => "F"
};
Console.WriteLine(grade);
Output
B
B
B

Classes & Objects oop
Class Basics Interview Fav
Fields, constructors, methods
public class Employee
{
    public string Name { get; set; }
    public string Role { get; set; }
    public decimal Salary { get; set; }

    // constructor
    public Employee(string name, string role, decimal salary)
    {
        Name = name;
        Role = role;
        Salary = salary;
    }

    public string Describe() => $"{Name} — {Role}";

    public void RaiseSalary(decimal pct) => Salary *= (1 + pct / 100);
}

var emp = new Employee("Robert", "BI Developer", 80000);
Console.WriteLine(emp.Describe());
emp.RaiseSalary(10);
Console.WriteLine($"New salary: {emp.Salary:C}");
Output
Robert — BI Developer
New salary: $88,000.00

Interfaces & Abstract Classes oop
interface vs abstract class Interview Fav
A class can implement many interfaces but only inherit one base class
public interface IShape
{
    double Area();
}

public class Rectangle : IShape
{
    public double Width, Height;
    public double Area() => Width * Height;

{

Properties & Auto-Properties oop
get / set, Computed & Read-Only Properties
public class Employee
{
    // auto-property — compiler generates the backing field
    public string Name { get; set; }

    // read-only property (init-only, C# 9+)
    public string Id { get; init; }

    // computed property — no backing field
    public string Greeting => $"Hello, {Name}!";

    // property with custom logic + private backing field
    private decimal _salary;
    public decimal Salary
    {
        get => _salary;
        set => _salary = value < 0 ? 0 : value;
    }
}

var emp = new Employee { Name = "Robert", Id = "E001", Salary = -100 };
Console.WriteLine(emp.Greeting);
Console.WriteLine(emp.Salary);   // 0 — the setter clamped it
Output
Hello, Robert!
0
Records & Structs oop
record vs class vs struct Modern C#
Records (C# 9+) give you value-equality and immutability for free
// record — reference type, built-in value equality, easy immutability
public record EmployeeRecord(string Name, string Role);

var a = new EmployeeRecord("Robert", "BI Developer");

// "with" expression — copy with one field changed
var promoted = a with { Role = "Senior BI Developer" };
Console.WriteLine(promoted);

try
{
    int result = 10 / int.Parse("0");

{
    Console.WriteLine($"Cannot divide by zero: {ex.Message}");

Nullable Types & Null-Coalescing error handling
?, ??, ??=, ?. Very Common
C#'s tools for avoiding NullReferenceException
// nullable value type
int? age = null;
Console.WriteLine(age.HasValue);      // False

// null-coalescing operator — default if null
int safeAge = age ?? 0;
Console.WriteLine(safeAge);

// null-coalescing assignment (C# 8+)
string role = null;
role ??= "Unassigned";
Console.WriteLine(role);

// null-conditional operator — avoids exceptions on null chains
string city = null;
Console.WriteLine(city?.ToUpper() ?? "Unknown");
Output
False
0
Unassigned
Unknown
LINQ Query Methods linq
Where, Select, OrderBy, GroupBy BI Essential
Think of LINQ as writing SQL directly against in-memory collections
using System.Linq;

var employees = new List<(string Name, string Dept, decimal Salary)>
{
    ("Alice", "IT", 90000),
    ("Bob", "HR", 70000),
    ("Carol", "IT", 85000),
};

// SELECT * WHERE
var itTeam = employees.Where(e => e.Dept == "IT").ToList();

// SELECT (projection)
var names = employees.Select(e => e.Name).ToList();

// ORDER BY
var bySalary = employees.OrderByDescending(e => e.Salary);

// GROUP BY + aggregate
var avgByDept = employees
    .GroupBy(e => e.Dept)
    .Select(g => new { Dept = g.Key, Avg = g.Average(e => e.Salary) });

foreach (var row in avgByDept)
    Console.WriteLine($"{row.Dept}: {row.Avg:C}");

// First/FirstOrDefault, Any, Count
Console.WriteLine(employees.Any(e => e.Salary > 88000));
Console.WriteLine(employees.Count(e => e.Dept == "IT"));
Output
IT: $87,500.00
HR: $70,000.00
True

async / await / Task async
Asynchronous Programming Interview Fav
Doesn't block the calling thread while waiting on I/O
public async Task<string> FetchReportAsync()
{
    await Task.Delay(500);  // simulate I/O (API call, DB query, file read...)
    return "Report data";
}

public async Task RunAsync()
{
    Console.WriteLine("Starting...");
    string result = await FetchReportAsync();
    Console.WriteLine(result);

    // run multiple tasks concurrently
    var task1 = FetchReportAsync();
    var task2 = FetchReportAsync();
    var results = await Task.WhenAll(task1, task2);
    Console.WriteLine($"Got {results.Length} results");
}

await RunAsync();
Output
Starting...
Report data
Got 2 results

public static T Max(T a, T b) where T : IComparable
    => a.CompareTo(b) > 0 ? a : b;

Delegates & Events advanced
Func, Action, Delegates, Events
C#'s way of passing functions as values / building pub-sub patterns
// Func<T, TResult> — a function that returns a value
Func<int, int, int> add = (a, b) => a + b;
Console.WriteLine(add(3, 4));

// Action — a function with no return value
Action<string> log = msg => Console.WriteLine($"LOG: {msg}");

// events — the standard pub-sub pattern
public class Report
{
    public event Action<string> OnGenerated;
    public void Generate() => OnGenerated?.Invoke("Sales Report");
}

var report = new Report();
report.OnGenerated += name => Console.WriteLine($"Notified: {name} is ready");
report.Generate();

ADO.NET — SQL Server data / sql server
SqlConnection / SqlCommand BI Essential
The classic way to query SQL Server directly from C# (WebForms-era and still common)
using System.Data.SqlClient;

string connStr = "Server=YOUR_SERVER;Database=YOUR_DB;Trusted_Connection=True;";

using (var conn = new SqlConnection(connStr))
{
    conn.Open();
    string sql = "SELECT TOP 10 ProductID, ProductName, Sales FROM dbo.SalesFact";

    using (var cmd = new SqlCommand(sql, conn))
    using (var reader = cmd.ExecuteReader())
    {
        while (reader.Read())
        {
            Console.WriteLine($"{reader["ProductName"]}: {reader["Sales"]:C}");
        }
    }
}

// parameterized query — always use parameters, never string-concat SQL
using (var cmd = new SqlCommand("SELECT * FROM Employees WHERE Id = @id", conn))
{
    cmd.Parameters.AddWithValue("@id", 42);
}
Output
(depends on your database content)
